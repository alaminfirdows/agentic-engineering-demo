## Pull request context
- PR diff: !`gh pr diff`
- PR comments: !`gh pr view --comments`
- Changed files: !`gh pr diff --name-only`

## Your task
Summarize this pull request in 2-3 paragraphs covering:
1. What problem does it solve?
2. What files/systems changed?
3. Any breaking changes or migration notes?

Keep it concise and focused on impact, not implementation details.
