# Top 25 Laravel + PHP Skills

Quick reference guide for activating the most valuable skills when working with Laravel and PHP.

## Core Laravel Architecture (1-7)

| Skill | Purpose |
|-------|---------|
| **laravel-specialist** | Laravel 10+ apps, Eloquent, Sanctum, Horizon, REST APIs, Livewire, Pest/PHPUnit |
| **laravel-patterns** | Architecture, controllers, services, queues, events, caching, API resources |
| **laravel-best-practices** | Conventions, models, migrations, validation, services, API development |
| **laravel-expert** | Production-grade architecture, performance, security, maintainability |
| **laravel-architecture** | Project structure, architecture decisions, design patterns |
| **laravel-project-patterns** | Repository-specific conventions, schema, factories, tests, tooling |
| **laravel-11-12-app-guidelines** | Laravel 11/12 workflows, Docker/Sail, Inertia, React, Blade, Fortify |

## Database & Eloquent (8-10)

| Skill | Purpose |
|-------|---------|
| **eloquent-best-practices** | Relationships, query optimization, N+1 prevention |
| **eloquent-best-practices-iserter** | Advanced Eloquent ORM optimization patterns |
| **laravel-database-optimization** | Query optimization, indexing, Redis caching, transactions, pagination |

## Security (11-13)

| Skill | Purpose |
|-------|---------|
| **laravel-security** | Authentication, authorization, CSRF, XSS, API security |
| **laravel-security-audit** | OWASP security audit for Laravel apps |
| **laravel-owasp-security** | OWASP Top 10, secure auth, payments, uploads, APIs |

## Testing (14-20)

| Skill | Purpose |
|-------|---------|

| **phpunit** | PHPUnit usage and configuration |
| **phpunit-best-practices** | PHPUnit testing standards |

## APIs & Backend (21-25)

| Skill | Purpose |

## How to Activate

1. **Inline**: Use `/skill-context-fork <skill-name>` to fork skills into context
2. **On-demand**: Skills auto-activate when you work in their domain
3. **Check existing**: Use `git grep` or `/explore` to find which skills a project already uses

**See also**: `/pin-files`, `/skill-context-fork`, `use-rtk.md`, `popular-plugins.md`
